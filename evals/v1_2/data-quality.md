# 固定50题质量检查

- 恰好50个唯一ID；A多城市、B预算时间、C天气重规划、D交通决策、E记忆住宿，各10题。
- 所有日期固定2026-10-10起，最长5天，处于版本化Rail/Flight Dataset的日期范围；无库存API假设。
- 逐题明确出发地、目的地、天数、预算，Query与实际请求对应。B01/B02为预算不可满足，B05为只坐高铁且12点前抵达不可满足；允许正确冲突，不允许虚假成功。
- D08所选近距离城市无固定航班，正确展示无航空候选；比较不是要求编造一个航班。D类包括单一方式硬限制、软偏好、换乘和避早班。
- E类偏好为独立本地SQLite种子；E02/E08/E10测试本次覆盖，E09真实执行初轮与Day2修订。长期不存聊天，transcript为公开的基准任务定义。
- request严格保留原始显式字段，避免schema默认值覆盖长期偏好。已用测试检查E01不含未指定节奏/兴趣/活动截止字段。
- evaluator独占hard_constraints、expected_agent_routes、required_tools和功能需求标签；runner只向生产接口传query/request/用户偏好/显式天气场景。
- 50题经过schema、分布、固定输入和离线执行预审。仍存在的路线/开放时间失败保留，不因结果不佳修改标签。
- 可复现边界：一次采样，非随机总体抽样；确定性Provider模拟能力覆盖有限。天气故障是明确模拟，不代表真实天气预报；LIVE能力另测。

验收时间：2026-09-21（北京时间，首尔时间跨 9 月 22 日）。真实请求均由用户授权；没有 commit、push、改写凭据或增加 Agent。

## 结论

Qwen `qwen-plus`、高德 Web Service、高德 JS API 2.0 均已真实验证。Chrome 中完成五天行程、暴雨修订和 200 元预算冲突，使用真实后端、真实模型、真实地图 SDK，没有拦截替换 LIVE 响应。Rail 保持 DATASET。

正常和暴雨最终为 `partial`、`validation.valid=true`：没有已知硬冲突，但开放时间、门票费用和预报覆盖仍有未验证项。不能把“跑通流程”描述为“全部旅行信息已确认”。200 元场景明确返回 `conflict`，不会生成虚假可行计划。

## 真实 API 与地图

- Qwen 最小 JSON 请求成功，schema 校验通过，服务返回模型名为 `qwen-plus`，没有静默回退。30 秒请求超时与两次有界尝试通过故障注入测试；未人为制造真实服务超时。
- POI 为高德返回的杭州西湖风景名胜区、灵隐景区；限定西湖区，避免富阳同名地点误匹配。
- 杭州天气为真实短期预报；当前预报不能覆盖 Dataset 的 2026-10-10 起五天日期。
- 西湖至灵隐驾车距离 6930 米；公交路线 76 分钟。二者交通模式不同，均来自高德，`source=amap_live`。
- JS 底图、Marker 名称、当天 POI、Day 1/3/5 切换与自动视野通过实际 Chrome 验证，截图显示对应杭州、南京、苏州真实底图。
- 最终真实浏览器 console error 0、page error 0、HTTP error 0；Provider 显示 Qwen LIVE、Amap LIVE、Rail DATASET，状态来自每次执行结果。

## 工作流与异常场景

执行经过 Supervisor、Transport、Local Travel、Travel Planner 的 Action/Observation、Critic 和最终行程。执行记录只包含代码生成的安全摘要，不展示私有推理或原始模型响应。

| 场景 | 最终状态 | 已知约束校验有效 | 模型请求 | 工具请求 | 重规划次数 |
|---|---|---|---:|---:|---:|
| 五天正常行程 | partial | True | 3 | 24 | 0 |
| 模拟暴雨 | partial | True | 4 | 24 | 1 |
| 200 元预算 | conflict | False | 5 | 24 | 2 |

暴雨先由 Critic 检出风险，再选择真实室内 POI、校验路线，最终没有天气硬冲突。暴雨是显式 `weather_simulation`，不是声称高德预报暴雨；Qwen、POI 和路线仍为 LIVE。室内候选有限时，同城多天可能重复场馆，未把有限候选包装成最优游玩方案。

200 元预算经有界调整后仍然超限，Critic 明确返回 `BUDGET_EXCEEDED`。住宿与餐饮采用预算占位，门票未知不视为免费。

## 本轮修复

- 兼容 DashScope 原生根路径 `/api/v1`，在同一配置主机转换至兼容路径，不更换账户区域或猜测模型。
- 实际 POI 查询优先主体景区的精确名称，其余保留高德相关性顺序，避免以最短名称选错场馆。
- 真实交通研究包含车站接驳，跨城到达日保守安排一个活动；更近的室内候选避免跨城接驳超出原有 120 分钟限制，没有放宽 Critic。
- 模型 final 有缺失路线时继续查询证据；暴雨修复明确安全优先于景点去重，保留两次自动重规划上限。
- 地图 SDK 初始化 JSONP 修复 MIME，保留 `nosniff` 与路径白名单；真实 SDK Marker 标签使用经转义的 HTML 字符串。
- LIVE 页面天气按钮明确标为“模拟暴雨 · 重规划”，避免将模拟描述为刷新真实天气。
